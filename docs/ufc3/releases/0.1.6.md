Native EA SPORTS UFC 3 port (PS4 `CUSA06534`, update 1.14) for Windows and Linux.
**No game files are included**: you need your own dump of the game and its 1.14 update.

Smoother fights with fewer GPU readbacks, a Windows launcher that fits small screens, and
`./ufc3.sh --play` on Linux. How to play online: [HOW-TO-PLAY-ONLINE.md](https://github.com/GNSB/UFC-3-PS4-PORT-LINUX-WINDOWS/blob/main/docs/ufc3/HOW-TO-PLAY-ONLINE.md).

### Performance

- **Exact write ranges** (PR #13 by @SinLeeke). When the game writes into memory next to
  GPU-written data, the port now knows the exact bytes the write touches instead of guessing with a
  16-byte margin, so writes that only sit beside GPU data no longer force a GPU readback.
  - **On by default:** the exact range of the game's `memcpy`/`memmove`/`memset`.
  - **Opt-in with `BB_WRITE_WINDOW=2`:** guest stores are decoded too. On a GTX 1650 at 1080p,
    fights went from 51.5 FPS with alternating 8/30 ms frames to 60–64 FPS, and readbacks dropped
    from about 25/s to about 4/s. On Linux: `BB_WRITE_WINDOW=2 ./ufc3.sh`. On Windows: set the
    environment variable before starting `SacredFire.exe`.
  - Details: [WINDOWS-EXACT-WRITE-WINDOWS.md](https://github.com/GNSB/UFC-3-PS4-PORT-LINUX-WINDOWS/blob/main/docs/ufc3/WINDOWS-EXACT-WRITE-WINDOWS.md).
- **New `BB_GUEST_FPS_LIMIT`** (off by default), also from PR #13. It is a frame limit applied on
  the game's own thread, so it adds no input latency, unlike `BB_FPS_LIMIT`, which holds finished
  frames.

### Launchers

- **Windows:** on screens shorter than the launcher (768p laptops, or 1080p at 125 % scaling and
  above), the window now fits the screen and scrolls, so Play, Stop and the log can be reached
  (#14). On screens where it already fit, nothing changes.
- **Linux:** `./ufc3.sh --play` starts the game directly with the settings saved in the launcher
  (game folder, name, language, video and online mode), without opening the window and without
  needing GTK, like `SacredFire.exe --play` on Windows (#12). `BB_GAME_DIR` overrides the saved
  folder, and `./ufc3.sh --play /path/to/CUSA06534` still works.

### Known issues

- At 150 % scaling on a 1366-pixel-wide screen, the Windows launcher is about 20 px wider than
  the screen.
- With `BB_WRITE_WINDOW=2`, some frames over 33 ms remain in some fights when the game reads
  GPU-written data.
- Keep the log folder on a local disk for the best FPS.
