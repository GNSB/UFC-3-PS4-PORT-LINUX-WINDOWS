Native EA SPORTS UFC 3 port (PS4 `CUSA06534`, update 1.14) for Windows and Linux.
**No game files are included**: you need your own dump of the game and its 1.14 update.

The real fix for the Career menu lag after the Super Fight / 2nd belt, a clean exit on Windows,
and a version check in every log. How to play online:
[HOW-TO-PLAY-ONLINE.md](https://github.com/GNSB/UFC-3-PS4-PORT-LINUX-WINDOWS/blob/main/docs/ufc3/HOW-TO-PLAY-ONLINE.md).

**Extract this release into a new, empty folder.** Do not extract it over or inside an older
version.

### Performance

- **Career menu lag after the Super Fight / 2nd belt** (PR #41 by @nomadsdad; #36, #18, #38,
  #39, #40). In the Career hub the port read full-screen render targets back from the GPU at every
  GPU fence, about 26 times per frame and about 2 ms each, which held the menu at 10–30 FPS.
  - **Now:** only the images the game needs on the CPU (storage images and tiny ones) are read
    back. Players confirmed the menu is back to normal, on v0.1.8 too.
  - **Also faster elsewhere:** on an RTX 3060 laptop, scenes with 500–900 draws per frame went from
    85 to about 100 FPS.
  - **To go back to the old behavior:** `BB_READBACK_LINEAR_ONLY=a`. `BB_READBACK_LINEAR_LOG=1`
    logs which images are read back.
  - The 0.1.8 change for this menu (`BB_DEPTH_AS_COLOR_REUSE`) stays: it was not the cause, but it
    saves repeated work.

### Fixes

- **Windows: the game no longer hangs on exit** (PR #42 by @nomadsdad). After a match, quitting
  from the game's menu could leave a white window that was not responding. The process now ends
  right away, after the logs are written.
- **Version check in every log** (so bug reports show the real version). The game, the GPU
  library and the Windows launcher now carry their own version.
  - The log starts with `Version: game …, GPU library …`, and crash reports show it too.
  - If the parts do not match (for example a new zip extracted over an old one), the log and the
    launcher show `VERSION MISMATCH: … extract the release zip into a new, empty folder`.

### Known issues

- With `BB_WRITE_WINDOW=2`, blood and sweat still do not show (#35), although it is about 20 %
  faster in heavy scenes. The default (mode 1) is not affected.
- The 2K/4K internal resolutions are still experimental.
