Native EA SPORTS UFC 3 port (PS4 `CUSA06534`, update 1.14) for Windows and Linux.
**No game files are included**: you need your own dump of the game and its 1.14 update.

**Stability fixes from shadPS4, plus two opt-in experiments.** How to play online:
[HOW-TO-PLAY-ONLINE.md](https://github.com/GNSB/UFC-3-PS4-PORT-LINUX-WINDOWS/blob/main/docs/ufc3/HOW-TO-PLAY-ONLINE.md).

**Extract this release into a new, empty folder.** Do not extract it over or inside an older
version.

### Fixes

- **Graphics stability: 8 fixes from shadPS4 (on by default).** Other native PS4 ports built on
  the same base had already brought them in; they are now in this port too:
  - GPU command waits between the constant and draw engines (#5406);
  - memory of nested GPU command lists is freed (#5258);
  - draws with a missing or unmapped index buffer no longer read garbage (#5358, #5327);
  - samplers with undefined fields are clamped to valid values (#5137);
  - GPU submits wait on all pipeline stages (#5231);
  - faster image lookups by address (#5240);
  - barriers for vertex, index and indirect buffers (#5262);
  - the first instance of indirect draws is counted once (#5348).
  - **The first start rebuilds the shaders once**, so expect some stutter in the first fight.
  - In the log, the `Backports:` line shows what is on. `BB_BACKPORTS=0` turns all of them off,
    and `BB_BP<number>=0` turns off just one (for example `BB_BP5262=0`). If anything looks wrong
    compared with 0.1.13, please try `BB_BACKPORTS=0` and tell us in an issue.
  - Two more are included but **off** (experimental): `BB_BP_RECONV=1` (maximal reconvergence in
    compute shaders) and `BB_BP5264=1` (early depth tests).

### Experimental (off by default, environment variables only)

- **Driver pipeline cache and background warmup: less stutter.** `BB_DRIVER_PIPELINE_CACHE=1`
  saves the GPU driver's pipeline cache to `user/cache/driver_pipeline_cache/` when the game closes
  and loads it on the next start; `BB_BACKGROUND_WARMUP=1` builds the known pipelines in the
  background while the game starts. In our test (RTX 4070, Linux) the worst hitch in a fight went
  from 250 ms to 166 ms. A damaged cache file is discarded and rebuilt, never a crash.
  Close the game normally (not by killing it) so the cache is saved.
- **Deferred GPU readbacks.** `BB_DEFERRED_READBACK=1` (and, on top of it,
  `BB_STALE_READBACK=1`) let only the thread that reads GPU results wait, not the whole GPU.
  Not measured yet: reports with `BB_FRAME_STATS=1` before/after are welcome. Stale mode turns
  itself off in online matches.

### Known issues

- In Quick Fight, blood on the body and the mat may only show after a cut (under investigation;
  Career is fine).
- With `BB_WRITE_WINDOW=2`, blood and sweat still do not show (#35). The default (mode 1) is not
  affected.
- CPUs without BMI1/MOVBE/LZCNT (Intel Core 2nd/3rd gen) are still not supported. PR #48 is under
  review.
