Native EA SPORTS UFC 3 port (PS4 `CUSA06534`, update 1.14) for Windows and Linux.
**No game files are included**: you need your own dump of the game and its 1.14 update.

**Intel Arc support (#52).** On NVIDIA and AMD nothing changes. How to play online:
[HOW-TO-PLAY-ONLINE.md](https://github.com/GNSB/UFC-3-PS4-PORT-LINUX-WINDOWS/blob/main/docs/ufc3/HOW-TO-PLAY-ONLINE.md).

**Extract this release into a new, empty folder.** Do not extract it over or inside an older
version.

### Fixes

- **Intel Arc GPUs: black 3D scene (#52).** On an Arc A580 the menus worked but the fighters,
  the octagon and the background were black. Intel GPUs run the game's shaders in smaller groups
  than the PS4's GPU and can produce invalid values (NaN) the console never does. This version
  turns on, **only with Intel's drivers** (Windows, and Mesa ANV on Linux), the shader fixes from
  mancelli's shadPS4 fork, tested there on an Arc B580:
  - shaders run in groups of 32 threads where the driver allows it;
  - extra synchronization of shared memory, also inside branches;
  - compute work declared in one dimension;
  - invalid values in colours and images are written as 0.
  - The first start on Intel rebuilds the shaders once. In the log, `GPU: Intel device` and
    `GPU: Intel workarounds` show what was turned on. `BB_INTEL_FIXES=0` turns everything off,
    for a test.
  - Not yet confirmed on real Intel hardware by us: **Intel Arc users, please tell us in #52
    whether the 3D scene now shows.**

### Known issues

- In Quick Fight, blood on the body and the mat may only show after a cut (under investigation;
  Career is fine).
- With `BB_WRITE_WINDOW=2`, blood and sweat still do not show (#35). The default (mode 1) is not
  affected.
- CPUs without BMI1/MOVBE/LZCNT (Intel Core 2nd/3rd gen) are still not supported. PR #48 is under
  review.
