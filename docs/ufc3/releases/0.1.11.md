Native EA SPORTS UFC 3 port (PS4 `CUSA06534`, update 1.14) for Windows and Linux.
**No game files are included**: you need your own dump of the game and its 1.14 update.

The main menu's images now show up right away, trophies are saved and announced, and Linux gets
an AppImage. How to play online:
[HOW-TO-PLAY-ONLINE.md](https://github.com/GNSB/UFC-3-PS4-PORT-LINUX-WINDOWS/blob/main/docs/ufc3/HOW-TO-PLAY-ONLINE.md).

**Extract this release into a new, empty folder.** Do not extract it over or inside an older
version.

### Fixes

- **Menu images load right away (#44).** Every time the main menu appeared, its tiles stayed
  empty for about 3 seconds, on every PC and on the Steam Deck.
  - **Cause:** when the game started a thread, the port made the new thread visible before setting
    it up. EA's thread library read an id of 0 at that moment, so a thread's timers could be
    delivered to another thread. The asset loader asked to be woken in 3 ms and slept 50–250 ms
    instead, once per image.
  - **Now:** a thread is set up before anyone can see it. The gap between menu images went from
    70–90 ms to about 3 ms. Other waits of the game use the same timers, so other screens may
    also feel quicker.
  - The same fix exists in PORTHEON's UFC 4 port (commit `5340e66`).

### New

- **Trophies (#45), offline.** Unlocked trophies are saved with their date in `trophies.json`, in
  the same data folder as your saves and logs. The game's own trophy list shows your progress, and
  a notification with the trophy's icon appears for about 4 seconds ("Trophy unlocked: #N").
  - The trophy names are encrypted in the game files. If you have your own trophy key, put
    `trophy_key=<32 hex digits>` in `bbport.ini` and the notification shows the real name. No key
    is included.
  - "Trophy notifications" in the in-game menu (**Insert** or **L3+R3**), or
    `trophy_notifications=0` in `bbport.ini`, turns off the notification. Trophies are still saved.
- **Linux AppImage (#49):** `UFC3Native-x86_64.AppImage`, next to the tar.gz. It opens the same
  GTK launcher. It uses the system's Python, PyGObject and GTK 4 (same requirements as the
  tar.gz), and keeps your data, saves and logs in `~/.local/share/UFC3Native`. Without FUSE, run it
  with `--appimage-extract-and-run`.
- **Linux logs:** a `System` line every minute shows CPU used by other programs, clocks,
  temperatures, power and battery. It helps tell whether a slowdown comes from the port or from
  the system (#47).
- **Diagnostics for bug reports:** `BB_FILE_TRACE=2` (file opens and reads with timings),
  `BB_EQUEUE_TRACE=1` (event queues and timers). Both are off by default.

### Known issues

- With `BB_WRITE_WINDOW=2`, blood and sweat still do not show (#35). The default (mode 1) is not
  affected.
- CPUs without BMI1/MOVBE/LZCNT (Intel Core 2nd/3rd gen) are still not supported. PR #48 is under
  review.
- The 2K/4K internal resolutions are still experimental.
