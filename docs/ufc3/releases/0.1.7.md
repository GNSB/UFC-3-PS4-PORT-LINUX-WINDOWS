Native EA SPORTS UFC 3 port (PS4 `CUSA06534`, update 1.14) for Windows and Linux.
**No game files are included**: you need your own dump of the game and its 1.14 update.

Two Career crashes fixed, and a clear message on CPUs the game cannot run on. How to play online:
[HOW-TO-PLAY-ONLINE.md](https://github.com/GNSB/UFC-3-PS4-PORT-LINUX-WINDOWS/blob/main/docs/ufc3/HOW-TO-PLAY-ONLINE.md).

### Crash fixes

- **Career crash in the "UI Update" thread** (null write at guest offset `0x1a3d204`; #25, #16,
  #18). When rendering fell behind, the game kept building new UI snapshots until its front-end
  heap ran dry. A UI scene built 8 times since the last frame now waits for the next frame (at
  most 250 ms). The log shows `UI back-pressure (UFC-57): on`. To turn it off:
  `BB_UI_BACKPRESSURE=0`.
- **Create Fighter crash while moving the appearance sliders or changing presets** (null write at
  guest offset `0x402882` on the RenderThread; #26, probably #20). The game's 4-entry appearance
  pool could be used up before the renderer freed an entry. Now a take or a publish that would use
  it up waits for that entry to be freed (at most 250 ms). The log shows
  `Appearance back-pressure (UFC-58): on`. To turn it off: `BB_APPEARANCE_BACKPRESSURE=0`.
- Both fixes check the game's code at startup and stay off if it does not match. If the game still
  crashes in these places, the log now prints more detail; please attach it to an issue.

### CPU requirement

- The game needs **AVX2, BMI1, MOVBE and LZCNT**: Intel Haswell (4th-gen Core) or newer, or AMD
  Ryzen. The README now says so (it said only "AVX"), and on an older CPU the Windows launcher shows
  why the game cannot start (exit code 24) instead of closing without a message (#21).

### Known issues

- The 2K/4K experimental resolutions in the launcher are still experimental. Both crash reports
  we received from them (on 0.1.5) are being looked into. If the game crashes with one of them on,
  try again without it before reporting.
- FPS can go down over long sessions and after changing arenas (#24).
