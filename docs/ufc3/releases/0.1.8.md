Native EA SPORTS UFC 3 port (PS4 `CUSA06534`, update 1.14) for Windows and Linux.
**No game files are included**: you need your own dump of the game and its 1.14 update.

Fixes for the Career menu FPS drop after winning belts, controller reconnects, blood and sweat with
`BB_WRITE_WINDOW=2`, and FPS going down in long sessions. How to play online:
[HOW-TO-PLAY-ONLINE.md](https://github.com/GNSB/UFC-3-PS4-PORT-LINUX-WINDOWS/blob/main/docs/ufc3/HOW-TO-PLAY-ONLINE.md).

### Performance

- **Career menu after the 2nd belt** (#36, #18). The menu background that appears after winning
  titles reads a shadow map as color, and the port converted it again for every draw that used it.
  Now the conversion is reused until the shadow map changes, which gives the same pixels with much
  less GPU work. To turn it off: `BB_DEPTH_AS_COLOR_REUSE=0`. The log shows a
  `Depth as color: … conversions/s, … reused/s` line every 5 s.
- **Long sessions** (#24, #32). Cached textures that the game had already overwritten were never
  freed while memory use was low, so on integrated GPUs (Steam Deck, Radeon 680M) the cache kept
  growing during a session. Textures that the game overwrote and that were not used for 60 s are now
  freed; they are uploaded again if needed. To turn it off: `BB_GC_STALE_SECONDS=0`. The log now
  shows a `Growth (60 s): …` line with the cache sizes, to find out what else grows.

### Fixes

- **Blood and sweat with `BB_WRITE_WINDOW=2`** (#35). In mode 2 a CPU write next to GPU data could
  overwrite up to 4 bytes of that GPU data with old values. Mode 2 now checks every byte that it
  hands back to the GPU. Mode 1 (the default) is unchanged. If blood or sweat still look wrong in
  mode 2, please attach a log made with `BB_WRITE_STORE_DIAG=1`.
- **Crash when the controller disconnects and reconnects** (#10). The port could restart SDL's
  controller system on one thread while another thread was using it. The restart is now locked, it
  waits 15 s after a disconnect so normal hot-plug can bring the controller back, and no closed
  controller is used again. The log shows `Pad: disconnected` / `Pad: reconnected` lines.

### Known issues

- These fixes were checked with automated tests and code review. If one of them does not fix your
  case, please reopen the issue with the new log; the new log lines tell us what is going on.
- The 2K/4K experimental resolutions are still experimental.
